Mr. Still — 개인정보처리방침

2026-10-24

Mr. Still은 로컬 이미지 뷰어입니다. 회원 가입, 광고 또는 분석 SDK, 사용자 추적 기능이 없으며 이미지, 메타데이터, 파일명, 폴더 경로, 사용 정보를 개발자나 서버로 전송하지 않습니다.

사용자가 여는 이미지와 폴더를 읽습니다. 이미지에 포함된 GPS 좌표 등 메타데이터는 기기 안에서 표시합니다. 기기의 현재 위치 권한은 요청하지 않습니다. App Store 버전은 macOS에서 사용자가 허용한 파일과 폴더에 접근하고, 재실행 후 접근을 복원하기 위한 보안 북마크를 Mac 안에 저장합니다.

환경설정, 창 배치, 즐겨찾기, 최근 항목, 파일 접근 북마크는 로컬에 저장됩니다. 즐겨찾기나 최근 항목에서 제거해도 원본 이미지와 폴더는 삭제되지 않습니다. 남아 있는 앱 설정과 북마크를 지우려면 앱 종료 후 로컬 앱 데이터를 제거할 수 있습니다. 복사, 붙여넣기, 삭제, Finder에서 표시, 인쇄는 사용자가 요청할 때만 수행합니다. 인쇄 및 클라우드 동기화 폴더에 저장된 파일은 사용자가 선택한 macOS 서비스, 프린터, 저장 서비스의 동작과 개인정보처리방침을 따릅니다.

앱은 개인정보를 판매하거나 공유하지 않습니다. GitHub로 문의하는 경우 제공한 정보는 GitHub 자체 개인정보처리방침에 따라 처리됩니다. 공개 이슈에 개인 사진, 경로, 메타데이터를 포함하지 마세요. App Store 결제와 선택적 시스템 진단은 Apple의 정책에 따라 처리되며, Mr. Still은 별도 결제 또는 분석 서비스를 운영하지 않습니다.
