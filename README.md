# Mr. Still

사진 폴더 탐색과 이미지 보기에 집중한 Swift/AppKit macOS 앱입니다. 외부 패키지 없이 Image I/O와 네이티브 파일·인쇄 UI를 사용합니다.

## 실행과 빌드

- 개발 대상: macOS 14 이상. 현재 실행 검증 환경은 Apple Silicon, macOS 26.6.2, Xcode 27.0입니다.
- 앱 이름: **Mr. Still**, 번들 식별자: `photoviewer.app.kryp.xyz`.
- 완성된 로컬 빌드: `build/DerivedData/Build/Products/Release/Mr. Still.app`
- Debug 빌드: `./scripts/build.sh Debug`
- Release 빌드: `./scripts/build.sh Release`
- 자동 테스트: `swift test`
- 합성 이미지 생성: `swift scripts/make-fixtures.swift build/Fixtures`

`PhotoViewer.xcodeproj`를 Xcode에서 열어 실행할 수도 있습니다. 새 Swift 소스 파일을 추가하면 `python3 scripts/generate-project.py`로 프로젝트를 갱신합니다. 기본 빌드는 개인 인증서가 필요 없는 로컬 ad-hoc 서명을 사용합니다. 개발자 서명이 필요한 경우 자신의 인증서와 Team을 명령행에서 지정합니다. 인증서·개인키·프로비저닝 프로파일은 저장소에 추가하지 않습니다.

```sh
./scripts/build.sh Release CODE_SIGN_IDENTITY="Apple Development: YOUR_IDENTITY" DEVELOPMENT_TEAM=YOUR_TEAM_ID
```

빌드 결과물, 개인 설정, 로컬 검증 로그와 스크린샷은 `.gitignore`로 제외합니다. 앱은 별도로 빌드해 실행하며, 이 저장소에는 설치용 바이너리를 포함하지 않습니다.

## 사용법

탐색기에서는 왼쪽 위 폴더 트리, 왼쪽 아래 이미지 목록, 오른쪽 뷰어를 사용합니다. 4pt 두께의 두 분할선을 드래그할 수 있습니다. 썸네일은 현재 너비에 맞춰 좌우 여백과 열 사이 간격을 동일하게 배분하며, 마지막 줄도 같은 열에 정렬됩니다. 경로 표시줄은 트리보다 밝은 배경으로 구분됩니다. 시작 시 홈의 직속 폴더만 펼쳐집니다. 창 너비를 바꾸면 오른쪽을 먼저 조절하고, 오른쪽 최소 너비에 도달한 뒤 왼쪽을 줄입니다. 초기 최소값은 왼쪽 280pt, 오른쪽 400pt, 폴더 트리 높이 160pt, 파일 목록 높이 240pt입니다.

폴더 트리의 ‘홈’ 위에 ‘즐겨찾기’가 있습니다. 폴더를 우클릭해 추가/제거하며 등록 순서는 재실행 후에도 유지됩니다. 폴더 우클릭의 ‘Finder에서 열기’는 해당 폴더를 열고, 파일 우클릭의 같은 메뉴는 Finder에서 선택 파일을 표시합니다.

경로 표시줄 왼쪽에는 테두리 없는 뒤로·앞으로·위로·새로고침 버튼이 있습니다. 위로는 상위 폴더를 열고, 새로고침은 선택과 방문 기록을 유지하면서 파일 목록과 현재 폴더 트리를 갱신합니다. 편집과 보기 사이의 이동 메뉴에서도 같은 동작을 제공합니다. 뒤로/앞으로 버튼, 마우스의 뒤로/앞으로 보조 버튼, Option+←/→로 폴더 방문 기록을 이동합니다. 세 화면과 슬라이드·전체화면에서 공통으로 작동합니다. 배율 입력칸 편집 중 Option+화살표는 텍스트 커서 이동을 유지합니다. 방문 기록은 실행 중에만 유지되며 같은 폴더 새로고침은 중복 기록하지 않습니다. 뒤로 이동한 후 새로운 폴더를 열면 앞으로 기록이 교체됩니다. 열기에 실패하면 기존 폴더와 선택을 유지합니다.

화면2에는 하위 폴더가 이미지보다 먼저 표시됩니다. 폴더를 더블클릭하거나 선택 후 Return을 누르면 해당 폴더로 이동하고 화면1도 동기화됩니다. 사진 앞뒤 이동은 폴더를 건너뜁니다.

이미지 목록 상단에서 작은/큰 썸네일과 목록 보기, 이름/수정일/용량 정렬, 오름/내림차순을 선택합니다. Shift 범위 선택, Command 추가 선택과 마우스 드래그 다중선택을 지원합니다. 여러 장을 선택하면 마지막 선택 사진과 장식용 겹침 표시를 보여줍니다. 복사/붙여넣기와 휴지통 이동은 이미지 파일에 적용됩니다. 폴더가 포함된 선택에서는 복사·휴지통 이동을 비활성화합니다. 동명 복사는 둘 다 유지, 건너뛰기, 취소 중 선택하며 자동 덮어쓰기는 하지 않습니다.

| 동작 | 입력 |
| --- | --- |
| 파일 / 폴더 열기 | ⌘O / ⇧⌘O |
| 폴더 기록 뒤로 / 앞으로 | ⌥← / ⌥→, 경로 왼쪽 버튼, 마우스 뒤로/앞으로 버튼 |
| 슬라이드 모드 | 파일 더블클릭, Return, 뷰어 더블클릭 또는 ⌘2 |
| 탐색기로 복귀 | 슬라이드에서 이미지 더블클릭, Esc, 하단 모드 버튼 또는 ⌘1 |
| 전체화면 토글 / 종료 | F 또는 ⌘F / Esc 또는 우측 상단 × |
| 이전 / 다음 사진 | 뷰어에서 ←·↑·Page Up / →·↓·Page Down, 좌우 화살표 버튼 |
| 확대 / 축소 | 뷰어에 포커스 후 ⌘+ / ⌘−, Option+스크롤 |
| 화면에 맞추기 | ⌘0 또는 하단 Fit 버튼 |
| 이미지 정보 토글 | I 또는 상태바 맨 오른쪽 ⓘ |
| 복사 / 붙여넣기 / 전체 선택 | ⌘C / ⌘V / ⌘A |
| 휴지통으로 이동 | ⌘Delete |
| 인쇄 | ⌘P 또는 파일 → 인쇄 |

슬라이드 모드는 왼쪽 패널을 숨깁니다. 전체화면은 진입 전 탐색기/슬라이드 모드를 기억합니다. 전체화면에서 마우스를 하단 44pt 영역으로 옮기면 상태바가 오버레이로 나타나고, 벗어나면 숨겨집니다. 배율 입력이나 정보 팝업을 사용하는 동안에는 유지되며, 나타나거나 사라져도 이미지의 크기는 변하지 않습니다.

하단 상태바의 배율·Fit·모드·전체화면·정보 버튼은 오른쪽 끝에 모여 있습니다. 정보창은 ‘그룹 / 항목 / 값’ 테이블이며 항목을 선택하면 하단에 전체 값이 나타납니다. 긴 값은 스크롤하거나 ‘값 복사’로 복사할 수 있습니다.

100%는 이미지 1픽셀을 화면 backing 1픽셀에 표시하는 배율입니다. 첫 로딩과 Fit은 작은 사진을 확대하지 않습니다. 최대 300%까지 소수 배율을 입력할 수 있으며, 자동 Fit과 작은 소수 입력에 1% 하한을 강제하지 않습니다. 표시는 소수점 두 자리까지이며 0.01% 미만은 `<0.01%`로 표시합니다. 내부 배율은 반올림하지 않습니다. 다른 사진을 선택하면 다시 Fit으로 돌아갑니다. I·F는 한글 입력 상태에서도 같은 물리 키로 작동합니다. 텍스트 입력 중에는 문자 입력이 우선합니다.

인쇄는 macOS 기본 패널에서 용지, 방향, 프린터와 PDF 저장을 선택합니다. 이미지 비율을 유지해 여백 안에 한 페이지로 맞춥니다.

## 지원 범위

- JPEG, PNG, HEIC/HEIF, TIFF, BMP, GIF. GIF와 다중 페이지 TIFF는 첫 프레임/페이지만 표시합니다. RAW, 영상, 편집과 자동 슬라이드 재생은 이번 범위에 없습니다.
- 정보창은 Image I/O가 읽은 EXIF/TIFF/GPS/IPTC 등의 중첩 속성을 표시합니다. GPS는 좌표로 제공하며 지도와 제조사 독자 메타데이터의 완전 해석은 후속 범위입니다.
- Finder의 ‘연결 프로그램’에서 앱으로 사진을 열면 해당 폴더와 파일을 선택합니다. ‘파일 → 기본 이미지 앱으로 설정’을 누르면 지원하는 7개 이미지 형식의 기본 앱을 Mr. Still로 일괄 설정합니다. macOS가 필요한 동의를 요청할 수 있으며 완료/실패 결과를 형식별로 표시합니다. 앱 실행이나 설치만으로는 기본 앱을 변경하지 않습니다. Finder Space 미리보기는 macOS Quick Look을 사용합니다.
- 목록 썸네일은 동시 디코딩 2개와 64MiB/600개 캐시 한도로 관리합니다. 뷰어는 현재 사진만 단계적으로 디코딩합니다. 극단적으로 큰 사진은 최대 128MP 또는 긴 변 32,768px로 표시 해상도를 제한하고 상태바에 알립니다. 인쇄는 원본 해상도를 요청하므로 큰 파일에는 추가 메모리가 필요합니다.

검증 결과와 미검증 환경은 [검증 기록](docs/validation.md), 화면·동작 규칙은 [DESIGN.md](DESIGN.md)에 정리했습니다.

앱 아이콘은 [미리보기](Resources/AppIcon-preview.png)의 사진·풍경 디자인을 사용합니다. `swift scripts/make-icon.swift`로 각 크기의 PNG와 ICNS를 다시 생성할 수 있습니다.

목록 보기의 이름·크기·수정일 열 제목을 클릭하면 해당 기준으로 정렬합니다. 다른 열은 오름차순으로 시작하고 같은 열을 다시 클릭하면 방향이 전환되며, 상단 정렬 옵션과 동기화됩니다.
